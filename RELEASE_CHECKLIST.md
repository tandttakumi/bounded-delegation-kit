# Release checklist

Before entering the Open Source Mini Challenge fields:

- [ ] Create public GitHub repo: `tandttakumi/bounded-delegation-kit`
- [ ] Upload/push the complete repository contents, including `LICENSE`
- [ ] Confirm GitHub shows **MIT license** near the top of the repo page
- [ ] Confirm README renders
- [ ] Confirm `tests/test_engine.py` is present
- [ ] Confirm no secrets, tokens, AWS account IDs, or private paths are present
- [ ] Run: `PYTHONPATH=src python -m unittest discover -s tests -v`
- [ ] In Devpost > Steward > Edit, replace the Open Source Mini Challenge fields with the values in `DEVPOST_OPEN_SOURCE.md`
- [ ] Keep Alexa+ and AWS Builder fields unchanged
- [ ] Save before Oct 23, 2026 12:00 PM PDT
